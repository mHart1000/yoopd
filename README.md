Video hotkeys plugin

Adds playback hotkeys to videos on any site. The standard controls (seek,
volume, play/pause) only kick in when the page doesn't already handle them, so
they never fight a site's own shortcuts.

] - speed up
[ - slow down
f - toggle fullscreen

→ - seek forward 5s
← - seek back 5s
↑ - volume up
↓ - volume down
space / enter - play / pause
c - toggle captions
